# Changelog

[← Documentation index](docs/README.md)

All notable changes to SSH Runner (the Flipper app, the ESP32 firmware and the `sshrunner` PC
tool) are documented in this file. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

One version covers all three parts: the release tag `v0.2.0` is the ESP32 firmware's version
and the PC tool's, and the Flipper app carries its major.minor (`0.2`).

## [Unreleased]

### Fixed

- `sshrunner backups import` refuses archive entries that name a Windows device (`NUL`,
  `COM1`) or an alternate data stream (`a.conf:x`) before writing anything.
- Hardened the app's text building so that a longer fingerprint or key file could never be
  written past its buffer (found by CodeQL; not reachable with today's sizes).

## [0.2.0] - 2026-10-25

First release, for the prototype on the Waveshare ESP32-S3-ETH; a custom add-on PCB is
coming in a later release.

### Added

- SSH from the Flipper over LAN (W5500) or 2.4 GHz WiFi through the ESP32-S3: Quick Connect,
  Hosts (each with its own commands, key and host-key policy), Recent, one-liners, saved
  commands and SD card scripts, output with exit code and duration.
- Password or key authentication: Ed25519, ECDSA and RSA keys from the SD card or generated by
  the app (Keys > Generate Key); an encrypted key needs its passphrase only once; the public
  key can be shown for `ssh-copy-id`-style setup.
- Host-key pinning per host: prompt, strict or off.
- Network: DHCP or static addresses per interface, WiFi scan and join (a failed join says
  why: wrong password, network not found, or other), automatic fallback between LAN and
  WiFi, ping through every interface or one.
- Large output: the first 1 KiB and the last 3 KiB are kept, the middle is skipped with a
  marker, and flow control never stalls the remote command.
- Optional at-rest protection of the board's secrets (Settings > Security > Protect Secrets,
  a permanent eFuse step).
- Built-in examples: nine read-only global commands and `scripts/sysinfo.sh`, copied once on
  the first start; Settings > Restore Examples adds back missing ones.
- Commands are at most 127 characters: the keyboard stops at each field's limit and shows
  `used/limit`; a longer command in a file is never cut (the host shows as unreadable, with
  the reason).
- `sshrunner`, the PC tool for Linux, macOS and Windows: edit hosts, commands, keys and
  scripts over USB or on the SD card; complete backups, private keys included (`--no-keys`
  leaves them out), one before every change (the newest 10 kept), with a Backups tab to
  restore, export and import; a pulled folder (public keys only) pushes back unchanged;
  `--json` output, shell completion, and "did you mean" for mistyped commands.
- Portable use: the board can run from the Flipper's GPIO header pin 9 (3V3) with its USB-C
  unplugged ([Hardware and Wiring](docs/HARDWARE.md)).
- One app build for the official firmware `1.5.1` and Unleashed `unlshd-094`, plus an optional
  Unleashed-only build.
